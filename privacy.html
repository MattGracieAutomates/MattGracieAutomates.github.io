Deal memos: privacy policy

Last updated: 2026-11-05

Deal memos is a private tool used only by its owner. This policy explains how it uses Google user data.

What Google data the tool accesses

The tool requests one Google permission: https://www.googleapis.com/auth/drive.file. With it, the tool can only see, create and edit the Google Drive files and folder it created itself (a folder named "Deal memos" and one Google Doc per property). It cannot see, read or change any other file in the Drive.

How the data is used

The tool creates and rewrites memo Docs in the owner's own Drive. It reads those Docs only to replace their content with an updated memo. It does not read any other Google data, such as email, contacts or other files.

Storage and sharing

The memos stay in the owner's Google Drive. The tool keeps a sign-in token on the owner's own computer and in the owner's private GitHub repository settings, so it can write the memos on a schedule. The tool never changes the sharing settings of any file, and never sells, transfers or shares Google user data with anyone. No Google user data is used for advertising or to train AI models.

Removing access

The owner can revoke the tool's access at any time at myaccount.google.com/permissions. Revoking access does not delete the memo Docs; they remain in the owner's Drive.

Contact

Questions: use the support email shown on the Google sign-in screen for this app.
